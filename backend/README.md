# Backend

The Express API and its three background workers. The API also owns the mining
orchestrator; the workers communicate with it through Redis.

| Process                   | Entry point                      |
| ------------------------- | -------------------------------- |
| API                       | `src/server.ts`                  |
| Contact-extraction worker | `src/messageWorker.ts`           |
| Email-verification worker | `src/emailVerificationWorker.ts` |
| Signature worker          | `src/emailSignatureWorker.ts`    |

Run them from the repository root:

```bash
npm run dev:backend-api
npm run dev:backend-worker
npm run dev:backend-email-worker
npm run dev:backend-email-signature-worker
```

Configuration comes from `backend/.env`, generated by `npm run dev:generate-env`
at the repository root. See [`.env.dev`](.env.dev).

For the process map, ports and request flow see [`docs/architecture.md`](../docs/architecture.md),
the mining stages in [`docs/mining-pipeline.md`](../docs/mining-pipeline.md), and
the HTTP surface in [`docs/api.md`](../docs/api.md).
