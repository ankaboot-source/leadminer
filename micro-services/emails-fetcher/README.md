# Emails fetcher

A Bun/Express service that fetches mail over IMAP or from PST files (and Google
Contacts) and streams messages into Redis for the backend workers.

It listens on port **8084** (`EMAIL_FETCHING_SERVICE_PORT`). Requests are mounted
under `/api`:

| Method | Path                    |
| ------ | ----------------------- |
| POST   | `/api/imap/fetch/start` |
| DELETE | `/api/imap/fetch/stop`  |

The same route file also exposes `POST|DELETE /api/pst/fetch/*` and
`POST|DELETE /api/google-contacts/*`.

## Run

Requires Bun >= 1.1.0 and a reachable Redis. From the repository root:

```bash
npm run dev:micro-services-emails-fetcher
```

Or from this directory:

```bash
bun install
bun run dev
```

Unit tests:

```bash
npm run test:unit
```

Configuration comes from `.env`, generated by `npm run dev:generate-env` at the
repository root. See [`.env.dev`](.env.dev).

The fetch stage and its Redis contract are described in
[`docs/mining-pipeline.md`](../../docs/mining-pipeline.md).
