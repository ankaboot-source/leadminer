# Agent instructions for `email-open-data`

This repository publishes email-domain and banned-IP lists for Leadminer. Read `README.md` for the data files and consumers. This file gives the rules an agent needs before it changes the refresh workflow or a list.

## What this repository owns

- The source lists: `free-email-domains.*`, `disposable-email-domains.*`, `public-email-providers.*`, `ISP-domains.*`, and `mailserver-banned-ips.*`.
- The refresh workflow `.github/workflows/fetch-new-data.yaml` (67 lines).

## Commands

```bash
# Run the refresh workflow manually
gh workflow run fetch-new-data.yaml

# Inspect the workflow
sed -n '1,80p' .github/workflows/fetch-new-data.yaml

# Check the file counts
wc -l *-domains.txt mailserver-banned-ips.txt
```

## Rules

### Do not edit a generated list by hand

The lists are generated by `fetch-new-data.yaml` and committed by the workflow (`fetch-new-data.yaml:72-73`). A hand edit is overwritten on the next run. Change the source URL or the merge logic in the workflow instead.

### Keep a domain in only one list

A domain belongs to only one list, except ISP (`README.md:14`). The workflow removes disposable domains from the free list and public domains from the free list (`fetch-new-data.yaml:43-44`). Do not add a domain to two lists.

### Do not change the raw URLs without checking the consumers

The backend reads `disposable-email-domains.json` and `public-email-providers.json` (`backend/src/fetchProviders.ts:10,13`). The ops repository reads `mailserver-banned-ips.txt` (`leadminer.io/blacklist-checker.sh:11`). Renaming or moving those files breaks a consumer.

## Gotchas

- The README claims hourly updates (`README.md:16`); the workflow schedule is daily at midnight (`fetch-new-data.yaml:4`). Check the actual schedule before promising freshness.
- The workflow downloads from third-party URLs. A source change breaks the workflow.
- The repository has no `AGENTS.md` today. This file is a proposal.

## Known gaps

- The README's hourly claim is not supported by the workflow schedule.
- The list sizes are large (`mailserver-banned-ips.txt` is about 8 MB). Do not load it into an agent context.
